# askhuman.app

Use askhuman.app when a human needs to open an HTML page generated by the agent.

## Required Flow

1. Run `curl -s https://askhuman.app`.
2. Generate exactly one self-contained HTML file.
3. Follow the returned OpenSSL + curl recipe.
4. Upload only encrypted JSON to `/upload`.
5. Append `#k=<86-character-base64url-key>` to the returned URL.
6. Give the final URL to the human.

## Rules

- Never upload plaintext HTML.
- Never send the key to the server.
- The key must remain in the URL fragment.
- Optional `title` and `filename` metadata are visible to the server; keep them generic if sensitive.
- The HTML should be self-contained.
- Links expire after 7 days.

## Payload

```json
{"version":1,"alg":"aes-256-cbc+hmac-sha256","title":"optional browser title","filename":"optional.html","iv":"...","ciphertext":"...","mac":"..."}
```

The browser reads the key from `#k=...`, verifies the HMAC, decrypts locally,
and renders the HTML in a sandboxed iframe.
